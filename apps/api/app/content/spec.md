# P4 content specification

Scope: TEAM.md Contracts, P4 lane; no API or gateway ownership changes.
Deliver three source-grounded golden topics before the generation pipeline, then
independent question/hint verification, migration 0005, evaluation and handoff.
Vietnamese learner content; source provenance; immutable chunk IDs; DAG validation;
exactly one correct option; misconception per distractor. No unverified content served.
Agent review, model verification and human approval are separate records.
Golden topics cover Python conditions, fractions and cells to exercise branching,
linear and broad prerequisite graphs across computational and descriptive subjects.

Acceptance: fake-gateway tests exercise leakage, identity, errors, stale verification,
hint release and confusion matrices; no mock result constitutes real verification.
No human reviewer is invented. TEAM-compatible exports exclude P4 internal metadata.
Spec Kit CLI/commands are not installed in this checkout; this local one-page spec,
plan and task list capture the required planning sequence without editing P2's setup.
