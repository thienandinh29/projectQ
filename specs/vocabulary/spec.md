# Spec: vocabulary (step 1.2 of `docs/v2/plan-english-pack.md`)

Vocabulary is the one part of the English pack with no prerequisite graph: a word has a CEFR level and a review
schedule, nothing else (owner's proposal). Mastery is not estimated with BKT here; FSRS decides when a word comes back.
Nothing in this feature calls an LLM: items are built from authored word data, so grading is exact and free.

## Word lists
1. A word list is a YAML file in `data/vocabulary/`. Each word has a lemma, part of speech, CEFR level (A1–C1), an
   English definition, an optional Vietnamese gloss, and authored practice material: example sentences with the
   target blanked, collocations, and word-family forms.
2. Checked on load: a lemma and part of speech are unique; the blanked answer really occurs in its sentence; a
   collocation phrase contains its blank; a form sentence has exactly one `___`; no empty fields.
3. The seed list `core-seed` is authored by the project (not copied from any source), about 24 words from A2 to C1,
   marked `status: draft` until the owner has reviewed it. Real word lists (NGSL, NAWL, CEFR-J) join only after their
   licences are verified (`data/sources/english-candidates.yaml`).

## Items (built from a word, deterministic, no stored state)
4. Four kinds: **meaning** (choose the word for a definition, multiple choice), **gap-fill** (type the missing word
   in an example sentence), **collocation** (type the word that completes a collocation), **word form** (type the
   right form of a given base word in a sentence).
5. An item id is `<list>|<lemma>|<pos>|<kind>|<n>`; the server rebuilds the item from the id alone, so the answer key
   never reaches the client and the server keeps no session state. Multiple-choice distractors are chosen
   deterministically from other words of the same part of speech and a nearby level; the same id always gives the
   same options in the same order.
6. **Typed answers are graded exactly** after normalisation, against the authored accepted answers. No fuzzy matching:
   a misspelled word is a wrong answer (IELTS marks spelling), and spelling variants such as colour/color are listed
   explicitly in `accepted`, never guessed. Normalisation (`graders/typed.py`) is the owner's to extend with tests.

## Practice
7. `GET /vocab/session`: the learner's due cards first (oldest due first), then new words up to a daily new-word
   limit (default 10) in list order from the lowest level, optionally capped with `max_level` (the level test of step
   1.3 will choose it). Each word gets one item, the kind rotating with how many times it has been reviewed. The
   response holds learner-safe items only.
8. `POST /vocab/answers`: grades the item, then schedules the word with FSRS (correct → Good, wrong → Again; no
   Easy, no hints, as `srs.rating_for`). A word's first answer creates its card. Each answer is appended to a review
   log and produces a `DecisionTrace` of kind `review` (stored under a subject for the word list), returned with the
   result in Vietnamese ("Vì sao?"). A wrong typed answer shows the accepted answer.
9. Answering an unknown or malformed item id is a 404/422; answering for an unknown learner is a 404.

## Not in scope
Real word lists, the level test, audio, the web screens (1.4), per-user limits, items generated by a model.
